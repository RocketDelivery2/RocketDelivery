# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability within this project, please take the following steps:

1. **Confidentiality**: Please do not disclose your discovery publicly before we have had a chance to investigate and respond.

2. **Contact**: Send an email to **security@rocketdelivery.com** with the subject line that includes the project name and a brief description of the issue.

3. **Provide Details**: Include as much information as possible regarding the vulnerability, such as:
   - Description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact of the vulnerability
   - Affected versions/examples if applicable.

4. **Patching**: We appreciate your assistance in helping to improve the security of our project. We will respond to your report within 48 hours!

## Security Updates

We will release updates or patches as necessary, and we encourage users to update their installations promptly to ensure their systems remain secure.
